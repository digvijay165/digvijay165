# Digvijay — Portfolio

A responsive portfolio site for [@digvijay165](https://github.com/digvijay165), built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser or serve this folder with any static web server.

## Features

- Responsive layout with accessible navigation and reduced-motion support
- Project filters for civic technology and browser tools
- Persistent light/dark theme toggle
- Public repository and star counts loaded from the GitHub API
- No build step, package manager, or API key required

## Deployment

This folder is intended to deploy as a static site from the profile repository's `portfolio/` directory.
